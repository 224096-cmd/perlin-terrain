# perlin-terrain

Pyodide を用いたブラウザ完結型プロシージャル地形生成学習教材（卒業研究）

公開ページ: https://224096-cmd.github.io/perlin-terrain/

現在の版: v1.5.0

## 概要

パーリンノイズ（自然な起伏を作る乱数の一種）による地形生成のしくみを、
ブラウザ上で Python コードを書き換えながら学ぶ Web 教材です。

- インストールや環境構築は不要です。ページを開くだけで Python が動きます。
- Python の実行も 3D の描画も、すべて利用者のブラウザの中で行います（サーバでは計算しません）。
- ホーム画面やデスクトップにアプリとして追加できます。

## 画面

| タブ | 内容 |
|---|---|
| 学ぶ | 11 個のステップ。説明と図を読み、課題に沿って Python コードを動かして、グラフと 3D の地形で結果を確かめる |
| 計測 | 端末の情報、Python の起動時間、地形の生成・表示時間を測り、CSV / JSON / Markdown で保存する |
| 記録 | 学習の履歴（実行回数、エラー、スライダー操作など）を集計し、CSV / JSON / Markdown で保存する |

## コードの動かし方

コードは 2 通りの表示で編集できます。どちらも中身は同じ Python のコードで、いつでも切り替えられます。

| 表示 | できること |
|---|---|
| ブロック | 1 文を 1 つのブロックとして表示する。つまみをつかんで（または ▲▼・矢印キーで）並び替える。枠で囲まれた数字や、ブロックの種類（"grass" など）をその場で書き換える。用意された部品を足す。複製・削除・元に戻す |
| テキスト | ふつうのエディタとして自由に書く |

- 書き換えると自動で実行され、結果がすぐ変わります（「変えたらすぐ実行」を外すと、ボタンで実行）。
- スライダーを動かすと、コードの `slider("名前", 最小, 最大, 値)` の「値」も一緒に書き換わります。コードの数字がいつも実際の値です。
- 実行のたびに、結果が前回から変わったかどうかを表示します。グラフには、ひとつ前の結果がうすい線で残ります。
- グラフは「線」と「ブロック」を切り替えられます。「ブロック」では、線の高さまで草・土・石のブロックを積んだ、地面の断面として表示します（1 次元のステップでも、3D と同じブロックの見た目で確かめられます）。
- 線が 2 本以上あるグラフは、「重ねる」（1 つの枠にまとめる）と「並べる」（線ごとに枠を分けて縦に並べる）を切り替えられます。「並べる」と「ブロック」を合わせると、それぞれの線がブロックの地面になります。
- 最初の表示はステップごとに決まっています（ステップ 1・2 はブロック、ステップ 5 はブロックを並べた表示、ほかは線）。切り替えた場合は、そのステップについて覚えておきます。
- 前のステップで学んだ関数は、ブロック表示では最初はたたまれています。そのステップで新しく出てくる部分には目印が付きます。
- エラーは日本語の説明と、Python の元の表示の両方を出します。

## 学習ステップ

| ステップ | タイトル | 学ぶこと | 表示 |
|---|---|---|---|
| 1 | 乱数だけで地面を作る | 乱数、シード値。となりと無関係なので、ばらばらになる | グラフ |
| 2 | 同じ形をくり返す | サイン波。なめらかだが、同じ山がいつまでも続く | グラフ |
| 3 | 点と点をなめらかにつなぐ | 格子点、線形補間、fade 関数 | グラフ |
| 4 | パーリンノイズ（1 次元） | 傾き（勾配）による補間 | グラフ |
| 5 | 3 つの作り方を比べる | 乱数・くり返し・パーリンノイズの地面を縦に並べて見比べる | グラフ（3 段） |
| 6 | 周波数と振幅 | 山の細かさと高さの調整 | グラフ |
| 7 | オクターブ合成 | 細かさの違うノイズの重ね合わせ、持続度 | グラフ |
| 8 | 3D の地形にする | 1 列の地面を奥へ並べる、1 次元のノイズを向きを変えて重ねる、どこまでも続く地形 | 3D |
| 9 | 3D でも 3 つの作り方を比べる | 乱数・くり返し・パーリンノイズの地形を横に並べて見比べる | 3D（3 つ） |
| 10 | ブロックの世界 | 条件の順番によるブロックの種類分け、低い所を水で満たす | 3D |
| 11 | 自分だけの島を作る | マスク、自由制作 | 3D |

教材は 1 次元（横 1 列の地面をグラフで見る）と 3D だけで構成しています。
3D の地形も、ステップ 4〜7 で作った 1 次元のパーリンノイズだけで作ります。場所 (x, z) を
「ある向きに沿って測った位置 p」に直して 1 次元のノイズを読み、これを向きを変えながら何本か足し合わせます。
ステップ 8 の「重ねる向きの数」を 1 にすると、ステップ 7 までの地面がそのまま奥へ並んだ形になり、
数を増やすと、どの向きにも起伏のある地形になります。

### 「なぜパーリンノイズなのか」を見比べる

この教材の中心は、次の 3 つの作り方の違いを、自分の目で確かめることです。

| 作り方 | となりとの関係 | 場所による形の違い | 地形として見ると |
|---|---|---|---|
| 乱数 | 無関係 | ある | ばらばらで、山や谷にならない |
| くり返し（サイン波） | なめらか | ない | 同じ地形がどこまでも続く |
| パーリンノイズ | なめらか | ある | 自然な山や谷になる |

- ステップ 1 と 2 で、乱数だけの地面と、くり返しだけの地面を、それぞれブロックの断面として見ます。
- ステップ 5 で、3 つの地面を縦に 3 段並べて見比べます（「右へ歩く」で、地面の先へ進めます）。
- ステップ 9 で、同じ 3 つをブロックの地形にして、横に並べて見比べます（「東へ移動」で、地形の先へ進めます）。

## 教材用の Python 関数

学習者のコードからは、次の 3 つの関数が使えます（定義は `py/prelude.py`）。

| 関数 | はたらき |
|---|---|
| `slider(名前, 最小, 最大, 値, 刻み幅=1)` | 画面にスライダーを作り、その値を返す。スライダーを動かすと、コードの「値」が書き換わって再実行される |
| `plot(ys, label="", xs=None, dots=False, width=2)` | 数値のリストを折れ線グラフ（または点）で描く。8 本まで描ける（重ねる / 並べる） |
| `terrain(heights, blocks=None, sea=None, label="")` | 行ごとの高さのリスト（リストのリスト）を渡すと、その高さ（ブロックの個数）だけブロックを積んだ 3D 地形を描く。`blocks` はマスごとのいちばん上のブロックの種類（その下は土や石で自動的に埋まる）。`sea` を付けると、その高さまで半透明の水が入る。何回か呼ぶと、呼んだ順に左から横に並ぶ（4 つまで）。`label` に書いた名前は、地形の上に札として出る |

`blocks` に使える名前: `water` `sand` `grass` `forest` `dirt` `stone` `snow` `ice` `lava`、または色コード `"#rrggbb"`（`colors=` と書いても同じ）。

ブロックの質感（草・土・石などのドット絵）は、画像ファイルを使わず、プログラムでその場で描いています。

## しくみ（データの流れ）

```
[画面: js/main.js]                         [Web Worker: js/py-worker.js]
 コード + スライダーの値  ── postMessage ──▶  Pyodide が Python コードを実行
                                             plot() / terrain() が呼ばれる
                                             Python の array.array を Float32Array にコピー
 グラフ / 3D の地形を描画 ◀── postMessage ──  ArrayBuffer を転送（コピーなしで受け渡し）
```

- Python は Web Worker（画面とは別のスレッド）で動くので、計算中も画面は固まりません。
- 終わらないコード（無限ループなど）は、20 秒で Worker ごと止めて作り直します。「止める」ボタンでも止められます。
- 3D 表示のプログラム（three.js）は、最初に `terrain()` が呼ばれたときに読み込みます。

## 書き出されるデータ

### 学習記録（記録タブ）の CSV の列

| 列 | 意味 |
|---|---|
| `timestamp` | 日時（UTC、ISO 8601 形式） |
| `session` | ページを開くたびに変わる ID（個人を特定する情報ではない） |
| `step` / `lesson` | ステップ番号と ID |
| `event` | `session_start` / `lesson_open` / `run` / `slider` / `block_edit` / `task_check` / `task_answer`（解説を開いた）/ `editor_mode` / `plot_style`（グラフの見た目や並べ方を切り替えた）/ `code_reset` / `stop` |
| `trigger` | 実行のきっかけ。`open`（ステップを開いた）/ `button` / `shortcut` / `edit`（書き換えによる自動実行）/ `slider` / `reset` |
| `ok` | 実行がエラーなく終わったか |
| `error_type` / `error_line` | エラーの種類（`NameError`、`Timeout`、`Stopped` など）と行番号 |
| `python_ms` | Python の計算時間 |
| `transfer_ms` | Python から画面側へのデータ受け渡し時間 |
| `render_ms` | グラフ・3D の表示にかかった時間 |
| `total_ms` | 実行を頼んでから表示が終わるまでの時間 |
| `code_chars` / `code_edited` | コードの文字数と、お手本から書き換えられているか |
| `outputs` | 表示したものの数（例: `plot:3`、`terrain:3`） |
| `slider_name` / `slider_value` | 動かしたスライダーの名前と値 |
| `detail` | 補足。`run` ではエラーメッセージ、または直前に行った編集の種類。`block_edit` では操作の種類（`move` 並び替え / `number` 数字 / `name` ブロックの種類 / `insert` 部品の追加 / `duplicate` 複製 / `delete` 削除 / `undo` / `redo`）。`task_check` では `task2=1` のように課題番号と印の有無。`task_answer` では課題番号。`plot_style` では `style=blocks`（線 / ブロック）または `layout=rows`（重ねる / 並べる） |
| `editor` | そのときの表示（`blocks` / `text`） |
| `result_changed` | `run` で、結果が前回の実行から変わったか |

記録は利用者のブラウザの中（localStorage）だけに保存され、外部には送信されません。最大 8,000 件で、古いものから消えます。

### 性能計測（計測タブ）の CSV の列

| 列 | 意味 |
|---|---|
| `size` / `cells` | 地形の一辺のマス数と、全体のマス数 |
| `octaves` | オクターブ数（4 で固定） |
| `trial` | 何回目の計測か |
| `python_ms` | `py/bench.py` を Pyodide で実行した時間（受け渡しを除く） |
| `transfer_ms` | Python の配列を Float32Array にコピーする時間 |
| `roundtrip_ms` | 画面側が実行を頼んでから結果を受け取るまでの時間 |
| `js_ms` | 同じアルゴリズムを JavaScript で実行した時間（1 回あたり） |
| `blocks_ms` | 3D 表示で、ブロックを並べて 1 回描き終えるまでの時間 |

JSON には、これに加えて端末情報と Python の起動時間が入ります。
